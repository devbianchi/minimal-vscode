# Custom VS-Code
---

Custom vscode settings.json for minimal look

## Installation

1. Install the extension "Custom CSS and JS Loader

2. Follow the installation steps

3. Create a custom folder to import files

4. Add to settings.json:

```
"vscode_custom_css.imports": [

        "file:///PATH/TO/FILE/custom-vscode.css",
        "file:///PATH/TO/FILE/vscode-script.js"
]
```

5. Restart vscode
